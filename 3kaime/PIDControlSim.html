PID制御シミュレーション：実験操作フロー

前実験で同定のモーターパラメータ ($\hat{a}, \hat{b}$) を用い、P, PD, PID 制御のシミュレーション実施。

1. シミュレーション準備

目的の理解: 同定モデルに基づき、P, I, D 各ゲインがモーター角度制御性能（応答速度、オーバーシュート、定常偏差、外乱抑制等）へ与える影響のシミュレーションによる確認と比較。
必要物品:
  • 前システム同定実験で取得の推定パラメータ $\hat{a}$ (a_est) 及び $\hat{b}$ (b_est) の値。
  • Python実行環境 (numpy, matplotlib 必要)。
  • 提供のPID制御シミュレーション用スクリプト（例: pid_simulation.py）。
コード準備とパラメータ入力:
  • シミュレーション用スクリプトのコードエディタ (VS Code 等) での展開。
  • スクリプト内 `a_est = ...` 及び `b_est = ...` 値設定箇所の特定。
  • 【重要】これらの値を、**自身がシステム同定で得た実際の $\hat{a}, \hat{b}$ の値へ正確に書き換え必須**。
  • シミュレーション設定（T_end, dt）と目標角度（target_deg）の確認（通常は変更不要）。
  • 外乱設定（add_constant_disturbance, constant_disturbance_accel, add_gaussian_noise, noise_std_dev 等）の確認・設定。（初回は一定外乱 add_constant_disturbance = True 設定推奨）
  • PIDゲイン（`Kp`, `Ki`, `Kd`）初期値設定。（次ステップでのP制御開始のため、Ki=0, Kd=0 へ設定）

2. シミュレーション実行とゲイン調整 (P, PD, PID比較)

本フェーズでは、Kp, Ki, Kd の値変更を伴う複数回シミュレーション実行により、各制御方式の特性比較・理解。毎回、ゲイン値と取得応答（グラフ形状、主要性能指標）の記録必須。

【実験 1: P 制御】 (比例制御)
  1. ゲイン設定: スクリプト内コントローラパラメータ部で、積分ゲイン Ki = 0、微分ゲイン Kd = 0 へ設定。
  2. 比例ゲイン Kp の値設定。まず小さい値（例: 50）から開始。
  3. （オプション）外乱設定確認 (add_constant_disturbance や add_gaussian_noise)。一定外乱有効化により定常偏差の視認性向上。
  4. シミュレーションスクリプト実行。
  5. 結果観察・記録 (P制御):
    • 角度応答の目標値到達有無、応答速度確認。
    • オーバーシュート有無確認。
    • **定常偏差:** 特に一定外乱存在時、目標値との定常的ズレ（定常偏差）残留有無確認。P制御限界の確認。
    • 制御入力（電流）の大きさ・形状確認。
    • Kp 値漸増時の、応答速度、オーバーシュート、定常偏差（外乱あり時）の変化、安定性維持有無確認。最適 Kp 範囲探索。
【実験 2: PD 制御】 (比例・微分制御)
  1. ゲイン設定: Ki = 0 維持。実験1での適切範囲 Kp 設定。
  2. 微分ゲイン Kd への正値設定（例: 1.0 から調整開始）。
  3. スクリプト実行。
  4. 結果観察・記録 (PD制御):
    • Kd の効果：P制御結果比較での応答変化確認（オーバーシュート抑制効果、振動抑制効果、応答速度への影響等）。
    • 制御入力（電流）初期挙動の P 制御比較での変化確認（スパイク状傾向）。
    • 定常偏差（外乱あり時）の P 制御比較での変化確認（理論上、PD 制御単独では一定外乱による定常偏差解消不可）。
    • Kd 値変更時の応答変化確認。過大時のノイズ影響懸念。
    • Kp と Kd の多様な組み合わせ調整による、速応性と安定性（オーバーシュート抑制）バランス良好な組み合わせ探索。結果記録。
【実験 3: PID 制御】 (比例・積分・微分制御)
  1. ゲイン設定: 実験2での良好応答を示す Kp と Kd の値設定。
  2. 積分ゲイン Ki への小さい正の値（例: 10.0 から調整開始）設定。
  3. （重要）一定外乱 (add_constant_disturbance = True) 有効化**による、積分項効果である定常偏差抑制の確認。
  4. スクリプト実行。
  5. 結果観察・記録 (PID制御):
    • Ki 追加による、PD制御比較での応答変化確認。
    • **定常偏差解消:** 一定外乱設定下での、**定常偏差解消有無確認。** これが積分項の主役割。解消所要時間確認。
    • 副作用: 積分項導入による、オーバーシュート増加、応答遅延、振動的挙動発生有無確認。
    • 制御入力（電流）定常値（外乱あり時）の変化確認（外乱打ち消しのための一定値出力確認）。
    • Ki 値変更時の、定常偏差解消速度や応答振動特性の変化確認。
    • Kp, Ki, Kd ３ゲイン調整（PIDチューニング）による、総合的良好性能（例：速い応答、少ないオーバーシュート、外乱下定常偏差ゼロ）達成目標。結果記録。
【方法 1: モデルマッチング / 極配置法 (計算による設計)】

本手法は、同定モーターモデルと目標応答特性に基づく、PIDゲイン計算。

  1. システムの伝達関数表現:
    • システム同定による取得モデル $\alpha(t) = \hat{a} I(t) + \hat{b} \omega(t)$ 考慮。ここで $\omega = \dot{\theta}, \alpha = \ddot{\theta}$。
    • ラプラス変換利用（初期値ゼロ仮定）により、$s\Theta(s) = \Omega(s)$, $s^2\Theta(s) = A(s)$ となる。
    • 上記関係より、モーター入力電流 $I(s)$ から出力角度 $\Theta(s)$ までの**プラント伝達関数 $G_p(s)$** は以下で算出可能： $$ s^2\Theta(s) = \hat{a} I(s) + \hat{b} (s\Theta(s)) $$ $$ (s^2 - \hat{b}s)\Theta(s) = \hat{a} I(s) $$ $$ G_p(s) = \frac{\Theta(s)}{I(s)} = \frac{\hat{a}}{s(s-\hat{b})} $$ ($\hat{a}, \hat{b}$ は同定パラメータ値)
    • PID制御器の**コントローラ伝達関数 $G_c(s)$** は： $$ G_c(s) = \frac{U(s)}{E(s)} = K_p + \frac{K_i}{s} + K_d s = \frac{K_d s^2 + K_p s + K_i}{s} $$ ($E(s) = \Theta_d(s) - \Theta(s)$ は誤差、 $U(s)$ は制御入力=電流 $I(s)$)
  2. 閉ループ特性方程式の導出:
    • 標準フィードバック制御系の**閉ループ伝達関数 $G_{cl}(s)$** は $\frac{G_c(s)G_p(s)}{1 + G_c(s)G_p(s)}$ で与えられる。
    • システム応答特性（安定性、速さ、振動等）は、閉ループの**極（特性方程式の根）**により決定。
    • **特性方程式**は $1 + G_c(s)G_p(s) = 0$ で与えられる。代入整理結果： $$ 1 + \left( \frac{K_d s^2 + K_p s + K_i}{s} \right) \left( \frac{\hat{a}}{s(s-\hat{b})} \right) = 0 $$ (両辺 $s^2(s-\hat{b})$ 乗算による分母除去) $$ s^2(s-\hat{b}) + \hat{a}(K_d s^2 + K_p s + K_i) = 0 $$ $$ s^3 - \hat{b}s^2 + \hat{a}K_d s^2 + \hat{a}K_p s + \hat{a}K_i = 0 $$ $$ \boxed{ s^3 + (-\hat{b} + \hat{a} K_d) s^2 + (\hat{a} K_p) s + (\hat{a} K_i) = 0 } $$ これを $P_{actual}(s) = 0$ とする。
  3. 目標応答と極配置:
    • 目標応答特性の**望ましい極配置 $p_1, p_2, p_3$** による指定。
    • 多くの場合、二つの共役複素極（主極 $p_{1,2}$）と、それより速い（実部がより負の）一つの実数極 $p_3$ 選択。主極は望ましい応答速度（自然周波数 $\omega_n$）と減衰比（$\zeta$）で決定。
      $p_{1,2} = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2}$ (if $\zeta < 1$), $p_3 = -k \zeta \omega_n$ ($k \ge 3$程度)
    • これにより、**望ましい特性方程式 $P_{desired}(s)$** 決定： $$ P_{desired}(s) = (s-p_1)(s-p_2)(s-p_3) = s^3 + C_2 s^2 + C_1 s + C_0 = 0 $$ ($C_2, C_1, C_0$ は $p_1, p_2, p_3$ または $\omega_n, \zeta, p_3$ から計算される係数)
  4. 係数比較によるゲイン計算:
    • $P_{actual}(s)$ と $P_{desired}(s)$ の $s$ の**同次項係数等価**による $K_p, K_i, K_d$ 決定。
      • $s^2$ 係数比較: $-\hat{b} + \hat{a} K_d = C_2 \implies K_d = (C_2 + \hat{b}) / \hat{a}$
      • $s^1$ 係数比較: $\hat{a} K_p = C_1 \implies K_p = C_1 / \hat{a}$
      • $s^0$ 係数比較: $\hat{a} K_i = C_0 \implies K_i = C_0 / \hat{a}$
    • ($C_2, C_1, C_0$ を $\omega_n, \zeta, p_3$ で表す具体的数式は、提供Pythonコード内 `calculate_pid_gains_pole_placement` 関数に実装済。)
  5. 【コード利用と検証】
    • Pythonコード内での目標性能 (`desired_omega_n`, `desired_zeta`, `third_pole_factor`) 設定。
    • スクリプト実行、コンソール出力の計算ゲイン Kp, Ki, Kd 確認。
    • コードによるこれらゲイン使用のシミュレーション自動実行と結果グラフ表示。
    • 表示応答の設定目標性能近接度（応答速度、オーバーシュート等）確認。

5. 全体の考察と比較、レポート作成

結果整理と比較考察:
  • モデルマッチング/極配置法設計ゲイン応答と、試行錯誤調整ゲイン応答の比較。
  • 各実験（P, PD, PID）での取得応答グラフ・性能の横断的比較・整理。
