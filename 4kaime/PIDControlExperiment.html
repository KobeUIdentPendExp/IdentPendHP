実機モーター角度PID制御 + 電流PI制御：実験操作フロー

カスケード制御（内側：電流PI＠ハッドウェア、外側：角度PID＠Python）を用います。両ループのゲインを試行錯誤で調整します。

実行準備:
  • 配布ファイルをProjectsフォルダにダウンロードしてください。
  • Vscodeなどのエディターでファイルを開いてください。
  • ターミナルでpython3 *.py (*はファイル名) または python *.py を実行してください。
  • 詳細はこちらで確認してください。

1. 実験準備と初期設定

目的: 実機を用いて、内側の電流PIゲインと外側の角度PIDゲインを試行錯誤により調整し、目標角度（例: 60度）への良好な追従性能を実現する。
ハードウェア接続・安全確認: 接続確認、回転範囲の障害物確認。
PC環境確認: Python環境、hid, matplotlib ライブラリ確認。
プログラム準備とパラメータ初期設定:
  • Pythonスクリプト（先生指定のファイル）を用意し、エディタで開く。
  • 【初期値設定】スクリプト冒頭のゲイン初期値を確認・設定する:
    • 電流PIゲイン (内): `desired_current_Kp`, `desired_current_Ki`。(推奨値または小さな値)
    • 角度PIDゲイン (外): `angle_kp`, `angle_ki`, `angle_kd`。(最初は `angle_ki=0`, `angle_kd=0`, `angle_kp` は小さな値)
    • 目標角度: target_angle_rad。
    • 制御周期: dt。
⬇️

2. ゲインの反復調整 (Iterative Tuning)

角度PIDゲインと電流PIゲインは相互に影響します。以下の流れを参考に、両者をバランス良く調整します。

調整の基本サイクル:
  1. 【角度PID調整 - まず動かす】`angle_kp` を調整し、モーターが目標角度に向かって**動き出す**ことを目指す（P制御）。
  2. 【電流PI調整 - 追従性改善】角度制御が動作している状態で、グラフの電流応答 ($I_{ref}$ vs $I_{meas}$) を見て、**電流誤差/遅延が最小**になるように `desired_current_Kp` と `desired_current_Ki` を調整する。
  3. 【角度PID調整 - 性能向上】 電流ループがある程度良好な状態で、グラフの角度応答 ($\theta_{ref}$ vs $\theta_{meas}$) を見て、**望ましい動作**（速応性、安定性、定常偏差ゼロ）になるように `angle_kp`, `angle_kd`, `angle_ki` を調整する（PD制御、PID制御）。
  4. 【繰り返し】 ステップ3の調整で $I_{ref}$ の挙動が変わり電流追従が悪化したら、ステップ2に戻って PI ゲインを再調整する。目標性能に達するまで、ステップ2と3を繰り返す。

【重要！】各制御実験実行前の必須リセット手順

注意： パラメータを変更して次の制御実験を行う**前には、必ず以下の手順でハードウェアをリセットしてください。

  1. モーター基板の**黒色電源スイッチを OFF** にする。
  2. PC と基板を繋いでいる **USB ケーブルを抜く**。
  3. 黒色電源スイッチを **ON** にする。（基板上の赤色とオレンジ色のLEDが点滅するはずです）
  4. USB ケーブルを PC に**接続する**。
  5. 基板上の**赤色ボタンを押す**。
  6. 赤色LED が点滅し、その後**消灯**するはずです。
  7. オレンジ色LED のみが**点灯**している状態（他のLEDは消灯）になれば、リセット完了です。
  8. PC 上で、(必要ならパラメータを修正・保存した) Python スクリプトを実行する。

この手順を怠ると、制御が不安定になったり、予期せぬ動作をしたりする可能性があります。
