Webots 環境設定 Q&A (macOS版)

macOS環境でのWebots利用時に発生しやすい問題と、その解決策をまとめています。

OpenMP / Pythonコントローラ関連

Q4: Webots実行時に "OMP: Error #15: Initializing libiomp5.dylib, but found libiomp5.dylib already initialized." と表示されます。

以下のステップで対処を試みてください。
  1. Pythonスクリプト内でのスレッド数制御 (診断的措置、根本解決ではない):
    OpenMPの衝突が並列処理に起因する場合、関連ライブラリが使用するスレッド数を1に制限することで、クラッシュが一時的に回避できるか確認できます。これは問題の切り分けに役立ちますが、根本解決ではありません。
    Pythonスクリプトの冒頭（主要な数値計算ライブラリや強化学習ライブラリのimport前）に以下を追加します: 
    
import os
os.environ['OMP_NUM_THREADS'] = '1'
os.environ['MKL_NUM_THREADS'] = '1'         # Intel MKL (NumPy等で使用)
os.environ['OPENBLAS_NUM_THREADS'] = '1'  # OpenBLAS (NumPy等で使用)
os.environ['VECLIB_MAXIMUM_THREADS'] = '1'  # macOS Accelerate framework
os.environ['NUMEXPR_NUM_THREADS'] = '1'     # Numexpr

# PyTorch (stable-baselines3が内部で使用) のスレッド数も制御
# import torch # stable-baselines3がインポートする際に設定されるのが理想
# torch.set_num_threads(1) # スクリプト内で明示的に呼ぶ場合
    もしこれでクラッシュしなくなった場合、やはりOpenMPの並列処理部分での衝突が強い要因であると推測できます。
